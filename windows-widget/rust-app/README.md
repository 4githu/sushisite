# NETAQ Windows 위젯과 앱

NETAQ의 웹 앱과 독립적인 바탕화면 위젯을 제공하는 Rust / Tauri 2 앱이다. 설치 후 바탕화면 위젯이 열리며 트레이 메뉴에서 웹 앱과 빠른 메모를 열 수 있다. 기존 Electron 위젯과 별개이므로 새 위젯의 계정 연결 화면에서 NETAQ 프로필 → 위젯 설치·연결의 연결 코드를 입력한다.

- 오늘 일정과 할 일, 메모를 표시하고 주간 날짜를 눌러 해당 날짜를 확인한다. 월간·할 일 보기와 빠른 기록, 완료 처리를 지원한다.
- 위젯 창은 드래그하거나 크기를 조절할 수 있다. 설정에서 항상 위, 자동 시작, 테마를 선택한다.
- 연결 토큰, 마지막으로 받은 일정과 임시 기록은 OS 보안 저장소의 키를 사용하여 암호화해 저장한다. 연결이 만료되거나 해제되면 개인 캐시를 지운다.
- 트레이 메뉴에서 위젯, 웹 앱, 빠른 메모, 항상 위, 자동 시작 및 종료를 선택한다. `Ctrl+Shift+M`은 빠른 메모를 연다. 단축키가 이미 사용 중이면 트레이 메뉴를 사용한다.
- 웹 앱은 별도 NETAQ 웹 로그인이 필요하다. 기존 Electron 위젯의 토큰은 자동 이전하지 않는다.

## 개발 및 빌드

Windows에서 Rust와 WebView2 및 Tauri 사전 요구 사항을 설치한 뒤 `npm ci`, `npm run dev` 또는 `npm run build`를 사용한다. macOS 교차 빌드는 LLVM/LLD, NSIS, cargo-xwin과 Windows x64 Rust 타깃이 필요하고 `npm run build:win-cross`를 쓴다.

0.3.0은 서명되지 않은 시험판이다. Mac에서 창·계정 연결 UI와 격리된 일정 데이터를 확인했으며 Windows x64 교차 빌드에 성공했다. 실제 Windows의 설치, 창 드래그, WebView2, 로그인, 트레이, 단축키, 자동 실행, 고해상도 디스플레이와 오프라인 복구는 실제 Windows PC에서 검증해야 한다.
