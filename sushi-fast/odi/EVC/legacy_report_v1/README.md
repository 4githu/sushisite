# Presentation report v1 snapshot

This directory is a read-only source snapshot taken before the evidence-aware
`presentation-report-v2` migration. It is intentionally not a Python package and
is not imported by the application.

The active implementation remains one directory above. The v2 JSON contract
keeps the v1 score, timeline, audience analysis, and AI insight paths so stored
v1 reports and older web clients remain readable.
