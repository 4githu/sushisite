## 후속 연동 설계

KAIST와 한양대는 공개 화면이 확인되어 연동 조사 우선 대상으로 적합합니다. 외부 사이트를 검색할 때마다 호출하기보다 허용된 제공 방식과 재사용 조건을 확인한 후 학기별 자료를 버전별로 가져와 내부 검색 캐시로 제공하는 구성을 권장합니다. 공개 조회 성공을 공개 API 제공이나 재배포 허가로 해석하지 않습니다.

- KAIST: 신·구 과목코드와 분반을 분리하고, 실험/연습 시간과 일반 수업시간을 구분합니다. 상호인정 표시만으로 졸업 학점 인정 여부를 확정하지 않습니다.
- 한양대: 캠퍼스·학기·수업번호로 강좌를 구분합니다. 같은 수업번호가 여러 설강학과에 반복되므로 학과별 결과를 그대로 중복 강좌로 만들지 않습니다.
- DGIST: 사용자 업로드 또는 학교가 제공하는 자료를 우선합니다. 학교 비밀번호를 서비스에 저장하거나 로그인 제한을 우회하는 방식을 사용하지 않습니다.
- 정원 수치는 관측 시각을 함께 보관하고, 갱신 실패한 값을 실시간 수치로 표시하지 않습니다.

학교 설정 → 내 학교 서비스 연결에 위 공식 주소를 등록해 바로 이용할 수 있습니다.
