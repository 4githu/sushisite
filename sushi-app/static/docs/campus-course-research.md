# 학교별 강의 연동

확인일: 2026-10-02.

학교 선택에는 서울대학교·KAIST·포항공과대학교·연세대학교·고려대학교·서강대학교·성균관대학교·한양대학교·GIST·DGIST·UNIST를 제공합니다. 학과는 학교별 목록에서 부분 이름이나 초성으로 찾습니다. 목록에 없는 학교·학과의 추가 입력도 유지합니다.

| 학교 | 강의 검색 | 학식 | 공식 이수규정 |
| --- | --- | --- | --- |
| 서울대학교 | 기존 연동 | 기존 연동 | 기존 연동 |
| 한양대학교 | 2026-1 5,483강좌 / 2026-2 4,961강좌, 서울·ERICA | 미연동 | 미연동 |
| 나머지 9개 학교 | 미연동 | 미연동 | 미연동 |

한양대 강의를 검색하고 시간표에 담으면 기존 자동 저장·캘린더 반영 경로를 사용합니다. 수강계획의 지난 강의 탐색에서도 두 학기를 조회합니다. 학교 등록 자체를 서비스 연동으로 표시하지 않습니다. 포털 URL 입력란은 제거했고, 확인된 공식 링크만 참고용으로 제공합니다.

## 확인한 원천

- [SNUTT](https://github.com/wafflestudio/snutt): README와 수집기 코드는 서울대 수강편람에 맞춰져 있습니다. MIT 라이선스이며 다른 학교에는 학교별 수집기를 연결해야 합니다. 이번 한양대 수집기는 독립 구현입니다.
- [한양대 공개 수강편람](https://portal.hanyang.ac.kr/sugang/sulg.do): 로그인 없는 공식 화면의 조회 경로로 학기 자료를 가져왔습니다. 인증정보·수강생 정보는 수집하지 않습니다. 공식 파트너 API 또는 재배포 허가를 뜻하지 않습니다.
- [KAIST 공개 개설교과목](https://erp.kaist.ac.kr/com/lgin/SsoCtr/initExtPageWork.do?link=estblSubjt): 비로그인 화면에서 2026 가을 미적분 18건 조회를 확인했습니다. 안정적인 자료 가져오기 경로는 아직 구현하지 않았습니다.
- [DGIST 안내](https://easyit.dgist.ac.kr/HOME/easyit/sub.htm?nav_code=eas1670825251): OneID 로그인 및 수강신청 기간 안내. 비로그인 전체 강좌 조회는 확인하지 못했습니다.
- [에브리타임](https://everytime.kr): 시간표·학식 기능은 있습니다. 외부 개발자용 공개 API는 확인하지 못했고, [이용약관](https://everytime.kr/page/serviceagreement)은 허가하지 않은 API 직접 호출 등을 제한합니다. 계정 로그인·비공개 API를 이용한 수집은 구현하지 않았습니다.

## 운영과 갱신

한양대 원천 호출은 사용자 검색과 분리한 운영자용 작업입니다. 검색마다 대학 서버를 호출하지 않으며 버전별 압축 카탈로그와 Web Worker 검색을 사용합니다. 정원·수강 인원 추이는 이번 한양대 연동에 포함하지 않습니다.

```sh
sushi-fast/.venv/bin/python ops/import_hanyang_catalog.py --year 2026 --term 10
sushi-fast/.venv/bin/python ops/import_hanyang_catalog.py --year 2026 --term 20
```

term은 10=1학기, 15=여름, 20=2학기, 25=겨울입니다. 고정된 공식 호스트만 조회하고 요청 간격은 1초입니다. 페이지 수·학기·중복 강좌 충돌을 확인한 뒤 새 파일과 인덱스를 게시합니다. 실패·빈 자료는 기존 인덱스를 대체하지 않습니다. 여러 가져오기 작업을 동시에 실행하지 마세요. 반영 후 백엔드를 재시작해 메모리 캐시를 교체합니다. 정기 갱신 스케줄은 아직 등록하지 않았습니다.

강좌 식별자는 캠퍼스·학기·수업번호·분반으로 생성합니다. 여러 설강학과에 나오는 같은 강좌는 한 번만 저장하고 학과 필터에는 모두 포함합니다. 갱신 날짜는 가져온 시각이며 실시간 갱신을 보장하지 않습니다.

학교별 학과 원천 URL과 확인일은 `sushi-fast/personal_project/data/campuses/directory.json`에 기록합니다. 학과 목록이 모든 학적·학위과정을 완전히 대체하지는 않습니다. 학교별 졸업 규정과 동등 과목에 서울대 규정을 임의 적용하지 않습니다.
