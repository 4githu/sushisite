# NETAQ 학교 서비스와 카카오톡 자료 공유

캘린더: https://netaq.chobab.app

## 자료 공유 사용법

자료 공유 게시판에 새 글을 저장하면 **대학생 자료 공유방**으로 제목, 본문, 게시글 링크와 이미지 묶음을 보냅니다. 기존 글을 수정하는 작업은 재전송하지 않습니다. PDF 등 일반 파일은 게시글 링크에서 게시판 권한을 확인한 뒤 다운로드합니다. 기존 게시판 글은 연결할 때 소급 전송하지 않습니다.

카카오톡에서 멘션 대상 선택으로 **김지후**를 실제 멘션하고 다음처럼 한 메시지로 보내세요.

```text
@김지후 자료 제목
여기부터 본문입니다.
여러 줄을 사용할 수 있습니다.
```

같은 메시지의 멘션 줄은 제목, 다음 줄부터 본문입니다. 이후 별도로 보낸 일반 대화는 포함하지 않습니다. 등록되면 같은 방에 제목과 게시글 링크로 완료 메시지를 보냅니다. 카카오톡의 인용 답장 기능으로 보내는 방식은 아닙니다.

Mac 접근성 API에 노출되는 **실제 멘션 강조 표시**와 이름을 함께 확인합니다. 단순 `@김지후` 문자열만 입력한 메시지는 제외합니다. macOS 알림 팝업을 수집하는 방식은 아니므로, 카카오톡을 보면서 대화하는 동안 팝업이 안 떠도 확인할 수 있습니다. 이 표시는 카카오톡 버전에 따라 달라질 수 있으며, 표시를 확인하지 못하면 일반 문자열만으로 자동 등록하지 않습니다.

## 첨부와 누락 시 처리

현재 수신 첨부는 멘션 **바로 뒤**, 같은 발신자·같은 분의 연속 사진/파일만 대상으로 합니다. 다른 사람이나 일반 메시지가 끼어들면 연결을 끊습니다. 앞서 보낸 사진, 나중에 따로 보낸 사진, 시간이 불명확한 첨부는 자동으로 연결하지 않습니다. 사진과 글의 관계가 모호하면 게시판에서 직접 첨부하세요.

수집 대상으로 확인된 첨부가 다운로드되지 않거나 권한 검증에 실패하면 게시글을 부분 저장하지 않고 관리자 화면에 대기 사유를 표시합니다. 일반 파일은 실행하지 않고 다운로드된 파일을 복사합니다. 수신 한도는 파일당 50MB, 계정 총 저장량 1GB입니다. 사진은 PNG 사본으로 저장되어 원본 인코딩·메타데이터와 다를 수 있습니다.

송신은 본문 10,000자, PNG/JPG/WebP 이미지 최대 10장·장당 8MB입니다. 초과 글은 자동으로 잘라 보내지 않고 오류로 남깁니다. 전송 클릭 후 결과가 불명확하면 `unknown`으로 남기고 자동 재시도하지 않습니다. 실제 대화방에서 확인한 뒤 수동으로 처리하세요.

## 운영 조건과 보안

- Mac이 켜져 있고 카카오톡이 로그인되어 있어야 합니다. 정확히 같은 이름의 방 하나만 열려 있어야 합니다.
- 현재 화면에 불러온 대화만 읽습니다. 공식 메시지 수신 API가 아니므로 Mac이 꺼진 동안의 모든 대화를 복구하거나 수신을 보장하지 않습니다.
- 30초 간격 확인 후 내용이 60초간 바뀌지 않으면 게시합니다. 데스크톱 UI 처리 시간만큼 더 걸릴 수 있습니다.
- 같은 내용의 멘션은 중복 방지를 위해 연결 내에서 한 번만 등록합니다. 다른 자료라면 제목이나 내용을 구분해주세요.
- 계정 메뉴 → 관리자 페이지 → 카카오톡 자료 공유에서 켜기·끄기와 오류를 확인합니다. Mac 연결 소유자이면서 게시판 관리자여야 설정할 수 있습니다.
- 게시판 API 키로 Mac을 제어할 수 없습니다. 글·댓글·파일 권한은 서버에서 검사하며 카카오톡 방에 전달된 본문·사진은 그 방 참여자에게 공개됩니다.
- 게시 전송 큐와 수신 출처를 따로 저장해 게시판↔카톡 순환 전송을 막습니다. API 키 폐기·게시판 권한 회수·글 삭제는 별도의 서버 검사를 따릅니다.
- 메시지 내용은 자료로만 처리합니다. 메시지를 명령으로 실행하거나 링크를 서버에서 자동 열지 않습니다.

게시글 자동 등록 API와 Python 예제: [board-api.md](./board-api.md).

## 학교 추가

학교 설정에서 서울대학교, KAIST, DGIST, 한양대학교를 선택하거나 새로운 학교·학과 이름을 입력해 저장할 수 있습니다. 별도 수강편람이 없는 학교는 수업을 직접 입력하고 학기 기간을 지정하면 캘린더에 자동 반영됩니다.

수강계획에서 학번·전공 유형별 사용자 규정을 기존 내용부터 수정합니다. 공식 검토본과 사용자 작성본은 분리하며, 사용자 규정은 공식 졸업 판정이 아닙니다. 학교 포털·학식·규정·시간표 링크를 등록할 수 있지만, 이는 외부 서비스 링크이며 자동 로그인·수강편람 수집 연동은 아닙니다.
