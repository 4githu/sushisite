## 실제 분석에서 찾은 오류

Azure TTS와 STT는 정상 연결됐으나 내용 훈련의 `message_clarity`가 `발화 근거를 확인하지 못했습니다`로 실패했다. AI가 인용문을 정확히 복사하지 않으면 전체 분석을 실패시키는 구조였다.

AI에는 원문 문장 목록과 근거 문장 번호를 요청하고, 서버가 선택된 원문을 그대로 결과에 넣도록 수정했다. 범위를 벗어난 번호는 거부하며, 외부 API 응답 형식은 기존 score/feedback/evidence를 유지한다. 원문 공백·문장부호 보존과 잘못된 인덱스 거부, 완료 저장 테스트를 추가했다.

실제 재검증은 개인 자료가 아닌 테스트 문장을 사용했다. Azure 한국어 TTS WAV 약 20.62초 → 실제 Azure STT → 발화 속도 분석 완료(100점), 메시지 명확성 실제 AI 분석 완료(85점)를 확인했다. 점수는 기능 검증용 샘플 결과이며 사용자의 점수가 아니다. 결과는 임시 DB에만 저장했다. 운영 사용자 기록은 만들지 않았다.

## 적용 범위와 남은 확인

프런트 변경은 현재 Vite 개발 서버에 반영된다. 백엔드 변경은 소스와 별도 실행 검증을 마쳤지만 현재 실행 중인 8000 서버는 자동 재로딩 모드가 아니다. 운영 재시작은 하지 않았다. 진행 중 EVC 세션이 메모리에 있으므로 내용 평가 수정 운영 반영에는 세션 사용 여부를 확인한 뒤 재시작해야 한다.

실제 VR 헤드셋/APK에서 발표하고 청중이 손들어 질문하는 동작까지 이번 검사에서 직접 수행하지는 않았다. 웹·서버 자동 검사 통과와 실제 Azure/AI 서비스 연결 성공을 VR 기기 전체 실연 검증으로 간주하지 않는다.
