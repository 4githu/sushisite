## 제공 기능

- KAIST/DGIST/한양대 기본 목록, 자유 학교·학과 등록, 학교별 안전한 HTTPS 링크. 미등록 학교에 서울대 강의·학식을 보여주지 않음. 학번 기반 수동 학기 시간표와 자동 일정 반영. 사용자 규정 기존 내용·revision 기반 편집.
- 게시판 4(자료 공유) ↔ 대학생 자료 공유방, 연결 소유자 3의 명시적 설정. 시작 시 과거 글·보이는 멘션을 baseline 처리. 최근 큐/수신/오류는 관리자와 기존 연결 화면에서 확인.
- 실제 멘션의 AXAttributedString 강조를 이름과 함께 확인. 문자열만 같은 글 제외. 멘션 메시지의 다음 줄부터 본문; 이후 일반 대화를 포함하지 않음.
- 말풍선 재활용에 따라 날짜/시각 AX 속성이 변하는 것을 확인해 동일 멘션 내용 중복을 보수적으로 억제. 같은 내용은 연결 내 한 번만 게시. 새로 불러온 과거 내용의 유입을 막는 시작 시각 검사.
- 소유자/관리자/게시판/자원 권한 재검사, 출처 기반 루프 차단, 일회성 전송 키. 삭제/수정된 대기 글 전송 차단. 불확실한 클릭 결과는 자동 재전송하지 않음.
- 사진 묶음 송신. 수신 첨부는 같은 발신자 바로 뒤 연속 항목만 후보로 삼고, 저장 검증 실패 시 부분 게시하지 않음. 앞서 보낸 사진·떨어진 사진과의 자동 연결은 제공하지 않음.
- 문서: `/docs/board-api.md`, `/docs/netaq-relay.md`.

## 검증

- 관련 백엔드 25개 테스트 통과: OAuth nonce/일회성/쿠키/목적, 학교 격리, 링크, 일반 문자열 제외, 수신 중복/quiet period/루프, 권한, 게시글 API 등. Svelte 검사 오류·경고 0, Node 운영 빌드 성공.
- 브라우저에서 미등록 학교·학과 저장, 수동 수업 등록과 16개 캘린더 회차 생성, 재진입, 규정 1판 저장 확인. 모바일 390px 규정 폼 검수·수정.
- 수동 수업 재진입에서 Worker에 Svelte proxy가 전달되는 오류를 발견, snapshot으로 변환해 해결.
- 운영 게시글 #5 → 카카오톡 본문과 사진 2장 묶음 전송 `succeeded`.

- 실제 멘션 `mentions=['김지후']`, 수동 문자열 비교 메시지 `mentions=[]`를 네이티브 AX 데이터로 확인. OS 멘션 알림 팝업을 감시하는 구현은 아님.

## 외부 설정 및 검증 한계

- Google 인증 화면에서 `redirect_uri_mismatch` 확인. OAuth 클라이언트에 **https://chobab.app/auth/google/callback** 등록이 필요. NETAQ는 이 콜백을 거쳐 nonce·암호화된 일회성 handoff로 돌아오며 주 로그인 쿠키는 host-only. 외부 콘솔 등록 전 Google 로그인은 완료되지 않음. 이메일 로그인 경로는 기존 방식 유지.
- 카카오톡 수신 사진/파일 전체 자동화는 실제 멘션과 파일 다운로드를 함께 끝까지 검증하지 못함. 발신자 변경을 넘겨 가져오지 않는 차단은 확인. Mac UI 변경/잠금/로그아웃/보이지 않는 과거 대화는 수신 누락 가능.
- 실제 멘션 판별은 현재 Mac 앱의 강조 스타일에 의존하며 공식 수신 이벤트/사용자 ID를 제공하는 API가 아님.
- 학교 링크는 자동 로그인이나 학교별 수강편람 API 연동이 아님. 데이터 없는 학교의 규정을 공식 요건으로 추정하지 않음.
- Google 콘솔 작업은 사용자에게 남김. 설정 체크리스트: `sushi-app/static/docs/google-oauth-setup.md`.
- 대학 검색 직접 검수: KAIST 2026 가을 `미적분` 18건, 한양대 비로그인 2026-2 `미분` 결과/시간/강의실 확인. DGIST 공식 안내는 OneID/신청 기간 제한. 조사와 후속 데이터 연동 구분: `sushi-app/static/docs/campus-course-research.md`.
