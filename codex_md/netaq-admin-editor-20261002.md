# NETAQ 관리자·게시판·편집기 개편

## 회원과 권한

초밥 계정 DB는 공통 로그인 원천으로 유지합니다. 서비스 DB의 `netaq_members`에 초밥 사용자 ID와 이용 기록만 저장합니다. 기본 관리자 목록은 NETAQ 이용자이며 초밥 계정만 있는 회원과 전체 계정을 별도로 조회합니다. 기존 학생 프로필·메모·프로젝트·게시글·개인 일정 기록을 이관하고, 이후 인증된 NETAQ 방문을 기록합니다. 과거 단순 로그인만 한 이용자는 당시 서비스별 기록이 없으므로 첫 재방문 전에는 미이용으로 보일 수 있습니다. 이관 시각은 과거 실제 가입일을 뜻하지 않습니다.

관리자는 현재 역할·학교/학과·실제 적용 권한·개별 ACL 값을 함께 보고 변경합니다. 상위 게시판 열람 제한과 명시적 거부가 하위 게시판/첨부/API에도 적용됩니다. 열람 차단 시 글쓰기와 댓글도 현재 적용에서 차단으로 표시합니다. 관리자 역할 변경에는 별도 화면 확인이 있고 서버 지정 관리자와 자기 자신의 권한 해제를 차단합니다. 변경 기록을 남깁니다.

## 게시판

- 일반 게시판을 먼저 표시하고 학과 게시판은 별도 그룹의 하위 게시판으로 생성합니다. 등록된 학교/학과 조합을 사용하고 해당 학과 회원만 볼 수 있습니다.
- 고유 시스템 키로 동시에 조회할 때의 학과 그룹·게시판 중복 생성을 차단합니다.
- 관리자에게 이름·상위 게시판·표시 순서·제한 공개 설정을 제공합니다. 순환 구조를 트랜잭션 안에서 차단합니다.
- 게시판 안의 가로 전체 게시판 메뉴 제거. 전체/상위/하위 게시판 탐색을 사용합니다.
- 글 수정 버튼을 제목 아래로 이동했습니다.
- API 키 화면은 관리자 연동·API로 이동하고 맥락 없는 다른 서비스 안내를 제거했습니다.
- 개인 자료/PDF 메뉴와 관리 화면 제거. 기존 자료 데이터와 게시판 첨부 API는 삭제하지 않았습니다.

## 편집기와 아우라

- 공통 편집기에 JSON 내보내기, 파일/붙여넣기로 가져오기, 교체 확인을 추가합니다. 기존 blocks 형식과 richContent/doc 형식을 처리하며 2MB 제한·schema 검증·문서 전환 중 늦은 파일 응답 차단을 적용합니다.
- 표에서 Tab/Shift+Tab으로 표 전체 들여쓰기/내어쓰기를 수행합니다. resizable TableView에도 실제 위치 변화를 적용했습니다.
- 아우라 기본 양식 저장의 native confirm을 화면 내 확인으로 교체합니다. 제출된 리포트도 새 양식으로 복사할 수 있지만 다른 기존 리포트는 변경하지 않습니다. 복수 회차 결합 문서는 하나의 회차 양식으로 자동 저장하지 않습니다.
