# 학생 기능·게시판·공통 편집기 배포 기록 — 2026-10-01

실제 학기별 내 시간표와 수강계획의 탐색 초안을 분리했다. 입학 연도/학년 보정으로 실제 학기를 표시하며, 시간표 저장 트랜잭션에서 소유한 캘린더 회차만 조정한다. 월간 숨김, 공휴일 제외, 기간 편집을 유지한다. 기존 학년별 초안은 백업 테이블에 원문을 보존하고 동일안 병합/다른안 탐색 초안 이전을 수행한다. 검색은 버전 캐시와 Worker로 옮겼고 필터/검색 조건을 URL에 유지한다. 개설 이력과 관측 시각이 있는 인원 추이를 제공한다.

규정은 공식본/사용자 판본 및 수정 이력을 분리하고 기존 내용을 채워 편집한다. 이수 예정과 완료를 구분하며 교양 분류와 과목 동등성 데이터를 포함한다. 문서에 표현되지 않은 복잡한 졸업 조건은 확인 필요로 표시하며 졸업 판정의 완전성을 보증하지 않는다. Class Checker의 공개 데이터를 참고하되 UI/검색 코드를 복제하지 않았다.

일반 게시판에 글·댓글·답글·검색·페이지 이동·공지·삭제/복구 및 서버 ACL을 추가했다. 개인 자료와 게시판 첨부는 인증과 현재 권한으로 보호한다. 자동 등록 API는 게시판/작업별 만료 토큰, 해시 저장, 폐기, 120회/분 제한, 생성 요청 중복 방지와 수정 revision을 사용한다. 문서와 Python 예제: `sushi-app/static/docs/board-api.md`, 배포 주소 `/docs/board-api.md`. 계정 관리자 지정은 `COMMUNITY_ADMINS`에서 운영자가 설정하며 임의로 사용자를 승격하지 않았다.

Tiptap/ProseMirror 편집기를 오늘 메모·자료·게시글·규정 설명·기존 Aura 편집기 경로에 적용했다. JSON v2와 이전 블록 투영을 함께 보존한다. 체크리스트·토글·표·파일/사진·붙여넣기·undo를 지원하며 메모는 로컬 복구/서버 revision을 사용한다. 충돌본은 별도 문서로 보존할 수 있다.

PDF.js 표시와 pdf-lib 벡터 주석 내보내기, 사용자별 필기·지우개·형광펜·텍스트·페이지 편집을 구현했다. 원본 PDF는 유지한다. PDF.js 6.3.289로 악성 PDF 실행 취약점을 패치하고 로딩 작업 종료 API 변경도 적용했다. Firebase의 하위 gRPC는 호환 가능한 1.x 패치로 override했고 DOMPurify도 패치했다. 최종 `npm audit --omit=dev`는 알려진 취약점 0개다. 전체 개발 의존성 감사에는 기존 도구 체인 취약점이 남아 있으며 운영 감사 결과와 혼동하지 않는다.
