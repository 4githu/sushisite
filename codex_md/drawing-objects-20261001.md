# 일간 일정 배경·그림 객체·편집 도구 개편

일간 일정은 별도 목록을 없애고 08:00~익일 02:00 필기장 안의 시간 좌표에 배치한다. 겹치는 일정은 열을 나누고 필기는 그 위에 놓인다. 이동 도구에서는 일정을 열 수 있고 필기 중에는 일정이 포인터를 가로채지 않는다. PDF 내보내기도 일정 배경을 합성한다. 시간 경계와 겹침, 종료 시각 없는 일정은 자동 테스트로 확인했다.

그림 메모는 별도 창에서 펜·형광펜·획 지우개·실행 취소로 작성한다. PNG와 원본 획을 이미지 노드에 함께 저장하며 다시 선택해 수정할 수 있다. 사진과 그림은 문서 내 드래그 및 위/아래 이동, 폭 조절, 좌/중/우 정렬을 지원한다. 자유 캔버스의 임의 x/y 배치가 아니라 문서 블록 객체다. 업로드 도중 문서가 바뀌면 첨부를 중단하고 기존 권한이 적용되는 공통 자료 저장소를 사용한다.

T 버튼으로 텍스트 서식 줄을 켜고 끈다. C 버튼은 본문 위에 작은 색상 팝업을 띄운다. 색 제거는 팝업 안에만 둔다. 표와 이미지의 부가 도구는 해당 객체를 선택할 때 나타난다. 토글은 접힘/펼침에 따라 회전하는 삼각형을 사용한다. Ctrl+Alt+Q 질문 색 막대와 설정을 제거하고 인용 단축키 Ctrl/Cmd+Shift+B를 안내한다. 기존 질문 메타데이터는 삭제하지 않으며 제출된 리포트는 일괄 수정하지 않는다.

관리자 링크는 메인 탐색에서 계정 메뉴로 옮겼다. 공란 회원 검색은 전체 회원 30명씩을 반환한다. 서버 관리자 검사·명시적 거부 우선 ACL은 유지한다. API 문서에 페이지 정보와 이미지 객체 속성을 추가했다.

검증: 백엔드 39개, 프런트엔드 14개 통과. Svelte 오류/경고 0, Node 빌드 성공. 그림 획·폭·정렬 JSON 왕복 보존, 공란 회원 검색/페이지 경계/비관리자 거부를 확인했다. 데스크톱에서 일정 배경과 기존 필기가 겹쳐 보이는 화면, 색상 팝업 전후 본문 offsetTop 동일을 확인했다. 모바일 390px에서 가로 넘침 없음. 그림 창 초기화 시 Svelte proxy의 structuredClone 오류를 발견해 snapshot 이후 복사하도록 수정했다.

브라우저 초안 이동 확인창으로 입력 조작이 차단되어 수정 후 그림 그리기→첨부→재편집·드래그의 전체 클릭 검수는 보류 중이다. 이 항목을 완료로 표시하지 않는다. 실제 Surface/S Pen 압력·하드웨어 지우개 검증도 남아 있다.
