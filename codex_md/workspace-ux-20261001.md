게시판 진입을 게시판 목록 → 글 목록 → 상세/댓글로 바꿨다. 자유 게시판, 자료 공유, 질문·답변을 초기 제공하고 글 수와 최근 제목을 표시한다. 기존 학과 전용 작성 화면은 제거하고 이전 주소는 일반 게시판으로 연결한다. 기존 제한 게시물은 권한을 유지한 채 보존한다. 관리자/자동 등록 API 설정은 글 읽기 흐름 아래로 옮겼다. 메뉴는 게시판/자료/학생/학식/수강계획별로 다른 아이콘을 사용한다.

내 시간표는 입학 연도와 학년 보정을 반영한 1-1, 1-2, 여름·겨울 계절 학기로 표시한다. 개설 카탈로그가 있는 학기만 선택하며 기본 시간표 및 수강 예정·이수 체크 UI를 제거했다. 수강계획 상단에 과거 강의 탐색과 규정 편집·업데이트를 노출한다. 규정 편집은 기존 값을 채우고 현재 전공 카드도 선택한 사용자 판본을 적용한다.

이수 현황은 종료일이 지난 정규 내 시간표에서 계산한다. 진행 중/미래 학기, 후보 초안/이전 대안은 제외한다. 동등 과목은 한 번만 계산하며 과거 해당 강좌 학점을 사용한다. 철회/낙제는 수강계획의 ‘계산 근거 · 역대 시간표와 미이수 조정’에서 제외/복원한다. 제외 기록은 사용자별로 분리하고 쓰기 Origin 검증을 적용한다. 직접 입력한 코드 없는 수업은 이수 요건 계산에 포함하지 않는다. 성적 증명이나 공식 졸업 판정은 아니다.
