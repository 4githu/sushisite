# NETAQ/Aura 남은 요청 구현·검증

요청 기준: 반복 일정·위젯, 학교 시간표/학점 분류, 공통 편집기, 게시판 채널/관리 권한, 카카오·DSHS 연동, 아우라 채점·퀵메모. 기존 ODI/인증 작업은 보존한다.

## 완료 기준

- [x] 반복 횟수 직접 입력/종료일 양방향 동기화, 일정 상세 완료 체크, 좁은 주간 화면
- [x] Android 장소 표시/일별 계획 이미지 위젯 및 APK 빌드
- [x] 학년·계절학기 버튼/추가학년/독립 연도, 실제 이력 기반 전공·교양 추가 분류
- [x] JSON 인접 버튼, 최근 형광색 단축키, 정렬, 이미지 선택 표시, 고정 편집바
- [x] 게시판 목록 버튼/채널 탭/채널 삭제복구/개별 관리자, 상단 우측 글 작업
- [x] 관리자의 일반 화면 접근 분리, 현재 권한 직접 편집 및 접근 가능한 학과 목록
- [x] 퀵메모 안 사진·평가·리포트 생성/출력, 기본양식 전환/저장, 학생 전환 보존
- [x] 클리닉 방 선택/이미지+안내문 전송, 모호한 수신자에서는 중단
- [x] 채점 회차·ZIP/PDF·답지/문항영역·감점/필기·OCR 검수·AI 피드백·JSON/Excel/PDF
- [x] PDF는 원본+코멘트 필기 유지, 문항 가이드/점수 박스는 제외
- [x] 카카오 누락/지연 원인과 긴 점검 주기의 안전성 검증 (불확실하면 확대하지 않음)
- [x] DSHS 자동 연동 작업자 가동·문서·PR
- [x] 운영 배포·응답·APK 확인 (PR 갱신은 아래 커밋에 기록)

Surface/S Pen 실기기와 Android 런처는 실제 기기 접근 전까지 검증 완료로 표시하지 않는다. Google OAuth 콘솔 설정은 사용자 담당으로 남긴다.

## 검증 기록

- 격리 DB 백엔드 89개, 공통 편집기/PDF/검색 단위 검사 14개 통과.
- 캘린더 16개, 아우라 학생 전환 2개, 채점·학년 연결 각 1개 브라우저 검사 통과.
- Android assembleDebug/lintDebug 성공, 기존 APK와 동일한 인증서 확인.
- 카카오 읽기에서 접근성 조회 중복을 줄였으며 지정 방 읽기를 확인했다. 로드된 메시지 범위만 보장하므로 30분 간격으로 늘리지 않았다. 과거 1시간 지연의 단일 원인은 확정하지 못했다.
- 검증 중 발견한 DB 격리 실패는 복구 후 conftest 선행 격리로 차단했다. 운영 사고 상세는 비공개 백업/복구 기록에 보존한다.

- 게시판 채널 이동·보관 복구·상단 글 작업의 데스크톱/모바일 검사 통과.
- 운영 도메인 적용, 새 APK 다운로드 바이트 확인, 비인증 관리자/채점 API 차단 확인.
