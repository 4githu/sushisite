# 필기·공통 편집기·게시판 접근 제어 — 2026-10-01

필기 SVG의 touch-action을 필기 모드에서 none으로 고정하고 이동 도구에서만 브라우저 이동·확대를 허용했다. 펜 전용 설정에서 손가락은 선을 그리지 않는다. 드래그 중 브라우저가 필기를 pointercancel로 바꾸는 원인을 제거했다. 일간 화면은 필기장 위에 오늘 일정을 시간순으로 표시하고 기존 일정 상세를 열 수 있다. 일정 생성 격자는 재도입하지 않았다. 실제 펜 하드웨어는 별도 확인이 필요하다.

게시판 글쓰기에 간단한 메모 첨부를 추가했다. 메모는 인용 블록으로 삽입하며 본문에서 수정 가능하다. 사진 붙여넣기·다중 첨부 다음에 다른 블록을 삽입해도 선택된 이미지를 덮어쓰지 않도록 삽입 위치와 다음 문단을 보장했다. 목록은 권한 검사된 이미지 URL을 lazy-load로 표시한다. 현재 목록 이미지는 원본의 축소 표시이며 서버 리사이즈 캐시는 별도 구현하지 않았다.

공통 편집기: 표 도구는 표 안 선택 시만 표시한다. 색상 팝업에 기본·최근·사용자 색과 제거를 제공한다. 형광 제거, 링크 연결/수정/제거, Tab/Shift+Tab 들여쓰기·내어쓰기, 코드 블록, 단순 삼각형 토글을 정리했다. 인용 전환 단축키는 Ctrl/Cmd+Shift+B다. Ctrl/Cmd+Alt+Q는 문단 왼쪽 색 막대를 전환한다. 질문 표시를 켜고 끌 수 있으며 기본은 꺼짐(저장된 표시가 있으면 켜짐)이다. 일반 문서는 JSON 블록 속성으로, Aura는 기존 questionChecks/블록 ID로 보존한다. 기존 형식은 읽기 변환으로 호환되므로 운영 리포트 일괄 재저장이나 제출된 리포트 변경을 하지 않았다.

자료 공유 게시판을 제한 게시판으로 마이그레이션했다. 명시적 board read 허용이 필요하고 명시적 거부가 우선한다. 문서/댓글/파일 및 기존 API 토큰 경로도 같은 ACL을 사용한다. 관리자 DB 역할 테이블과 관리 변경 기록을 추가하고, 사용자가 지정한 기존 계정 하나에만 관리자 역할을 부여했다. 계정 이메일이나 비밀키를 코드에 하드코딩하지 않았다. 관리자 화면은 회원 검색, 게시판 제한 설정, 회원별 read/post/comment/manage 허용·거부·기본값 복원, 변경 기록을 제공한다. 관리자 데이터 API는 서버에서 관리자 여부를 검사한다.
